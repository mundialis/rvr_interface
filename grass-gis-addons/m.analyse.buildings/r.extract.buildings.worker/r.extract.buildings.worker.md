## DESCRIPTION

*r.extract.buildings.worker* is a worker module that is started by
[r.extract.buildings](r.extract.buildings.md). It extracts buildings as
vectors using an nDSM-raster, NDVI-raster, and FNK-vector
(Flaechennutzungskartierung).
