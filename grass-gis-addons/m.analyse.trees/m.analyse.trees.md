## NAME

***m.analyse.trees*** - GRASS GIS addons for detection and comparison of
single trees and calculation of various tree parameters for them.

## KEYWORDS

[raster](https://grass.osgeo.org/grass-stable/manuals/raster.html),
[vector](https://grass.osgeo.org/grass-stable/manuals/vector.html)

## DESCRIPTION

The *m.analyse.trees* toolset consists of several modules.

- [v.tree.param](v.tree.param.md): Calculates various tree parameters
  for given treecrown vector map
- [v.tree.param.worker](v.tree.param.worker.md): Worker for parallel
  processing of **v.tree.param**

## REQUIREMENTS

The following Python libraries are needed.

- psutil
